
# WaveCore Research

Открытый научно-исследовательский проект
по вычислительной электродинамике,
численным методам и моделированию
телекоммуникационных систем.

## Основные направления

- Уравнения Максвелла и Гельмгольца
- Электромагнитные и волновые процессы
- Численные методы FDTD, FDFD и FEM
- Комплексные разреженные матрицы
- Итерационные методы решения СЛАУ
- Моделирование радиоканалов 5G/6G
- Высокопроизводительные вычисления

## Научные публикации

### 01. Физические основы электромагнитных волн
